# איך להתחיל עם Claude Code

החבילה הזו מוכנה. הקוד מתקמפל, הבדיקות עוברות, הבנייה מצליחה.
Claude Code לא מתחיל מאפס — הוא ממשיך מבסיס מאומת.

## הפרומפט הראשון — העתיקי כפי שהוא

```
קרא את CLAUDE.md במלואו, ואז את docs/SPEC.md.
זהו פרויקט משחק גוונים על גלגל הצבעים. הבסיס כבר בנוי ומאומת:
המנוע ב-src/engine/ עובר 13 בדיקות, והאפליקציה נבנית בהצלחה.

המשימה הראשונה: הרץ npm install && npm test && npm run dev,
ודא שהמשחק עולה, ואז כייל את הגוונים ב-src/engine/wheel.ts
מול reference/image.png — פתח את שני הקבצים והשווה פלח-פלח.
דווח לי מה שינית לפני שתמשיך.
```

## מה כבר עובד — אל תבנה מחדש

- **המנוע** (`src/engine/`) — קטלוג, ניקוד, AI, reducer. פונקציות טהורות.
- **הרכיבים** (`src/components/`) — גלגל, מגש, הכרזה, הסבר, ספר, אבחון.
- **הבדיקה** (`tests/catalog.test.ts`) — מאמתת 597. הרץ אחרי כל שינוי במנוע.

## רצף מומלץ אחרי הכיול

1. **כיול גוונים** — הצעד הראשון, מול התמונה. הערכים ב-`wheel.ts` הם קירוב.
2. **חומריות הזכוכית** — השווה אבן מונחת ל-`reference/harmonia.html`.
3. **שרטוט הצורה החתימתית** — ודא שהמשולש/המרובע/הקשת מופיעים ודוהים.
4. **מובייל** — הגלגל למעלה, המגש בתחתית, ספר ההרמוניות כמגירה.
5. **נגישות** — פוקוס מקלדת על התאים, `prefers-reduced-motion`.
6. **פרסום** — deploy, README, שם מקצועי.

## הרחבות אפשריות (אחרי שהבסיס יציב)

- **מלחין אמיתי** — מינימקס 2–3 מהלכים קדימה. ראו CLAUDE.md ממצא 4:
  היוריסטיקה נבדקה ונכשלה, חיפוש לעומק הוא הדרך היחידה שהוכחה כמבטיחה.
- **מצב לימוד** — משחק חופשי ללא יריב, לצפייה בהרמוניות מצטיירות.
- **דיאגרמות זעירות** בספר ההרמוניות — גלגל קטן לכל הרמוניה שנמצאה.
