# הַרְמוֹנְיָה

**לשחק עכשיו (כתובת ציבורית):** https://anat1969.github.io/COLOR_GAME-GH/

משחק לימוד התאמת גוונים על גלגל הצבעים. שבץ-נא של צבעים: מניחים אבני
זכוכית על גלגל בן 60 גוונים (12 פלחים × 5 טבעות), והניקוד ניתן על
היחסים הגיאומטריים בין הגוונים. כל אורך-צירוף — 2 עד 7 — מקודד יחס
קומפוזיציוני אחר: ניגוד, דירוג, סדר, תנועה, מקצב, מחזור.

**המטרה אינה הניקוד — היא המיומנות.** המשחק מלמד לזהות יחסי צבע ולראות
קומפוזיציה כמבנה חשיבה.

## הפעלה

```bash
npm install
npm run dev        # שרת פיתוח → localhost:5173
npm run build      # בנייה לייצור → dist/
npm run build:play # קובץ אחד ללחיצה → ../הרמוניה.html
npm test           # בדיקת הרגרסיה (30 בדיקות)
```

### לשחק בלי טרמינל

`npm run build:play` בונה קובץ HTML **יחיד ועצמאי** ומניח אותו בתיקיית המשחק
הראשית בשם `הרמוניה.html` (ליד `גלגל ניוטון.jpg`). כל ה-JS וה-CSS מוטמעים
בתוכו כסקריפט קלאסי, ולכן **לחיצה כפולה עליו פותחת את המשחק בדפדפן — בלי שרת
ובלי טרמינל.** (הגופנים נטענים מ-Google Fonts; עם אינטרנט הטיפוגרפיה מלאה,
בלעדיו נופלת לגופן ברירת מחדל והמשחק תקין.)

> קובץ המקור `index.html` והתיקייה `dist/` הם חלק מפרויקט Vite ואינם נפתחים
> בלחיצה כפולה — דפדפנים חוסמים טעינת מודולים מ-`file://`. הקובץ ללחיצה הוא
> `הרמוניה.html` בלבד.

## שמירה לגיטהב וכתובת ציבורית

הפרויקט מגובה ב-GitHub: `github.com/Anat1969/COLOR_GAME-GH`. כל דחיפה ל-main
מפעילה אוטומטית את `.github/workflows/deploy.yml`, שבונה את המשחק ומפרסם אותו
לכתובת החיה **https://anat1969.github.io/COLOR_GAME-GH/**. כל התמונות והטקסט
נשמרים בהיסטוריית הגרסאות של git — שום שינוי לא הולך לאיבוד.

**לשמור שינוי (הדרך הקלה):** לחיצה כפולה על `שמירה-לגיטהב.cmd` בתיקייה
הראשית. הוא שומר הכול, דוחף לגיטהב, והאתר החי מתעדכן תוך כדקה.

**או ידנית מטרמינל:**

git add -A && git commit -m "תיאור השינוי" && git push

## החלטות מפתח

הידע שהושג מתועד במלואו ב-`CLAUDE.md`. בקצרה:

- **הרמוניה מזכה רק עם ≥2 אבנים חדשות בתור** — אחרת המשחק מתגמל השלמה מקרית ולא תפיסה.
- **אין כלל השקה** — כל תור חייב ליצור הרמוניה. האילוץ קומפוזיציוני, לא מרחבי.
- **גודל היד תלוי ברמה** — 7 בפתיחה, 9 ברמות הגבוהות.
- **היריב חמדני** — היוריסטיקת חסימה נבדקה ונכשלה; מלחין חזק ידרוש חיפוש לעומק.

- **הגוונים נדגמו, לא נוחשו** — טבלת 12×5 ב-`src/engine/wheel.ts` נמדדה
  פיקסל-אחר-פיקסל מ-`reference/image.png`. הבהירות מוסדרת להיות מונוטונית
  יורדת בתוך כל פלח, כי הניקוד מניח שטבעת = מדרגת ערך.
- **הזכוכית וקטורית** — האבן ב-`src/components/Gem.tsx` בנויה משכבות
  (כיפה, בליעת קצה, קאוסטיקה, ברק, שפה) ולא מפילטר רסטר, ולכן היא נשארת
  חדה בכל הגדלה ו-60 אבנים אינן עולות יותר מאבן אחת מטושטשת.

## כלי בדיקה חזותית

רינדור הגלגל ל-SVG סטטי, מחוץ לדפדפן — שימושי להשוואה מול תמונת הייחוס:

```bash
npx esbuild scripts/shot.tsx --bundle --format=esm --platform=node \
  --external:react --external:react-dom --outfile=scripts/shot.mjs
node scripts/shot.mjs 4 1 board.svg      # רמה 5, לוח מלא
```
